# TaSQ built-in SVG icons

These 12 monochrome vector assets are embedded into the executable at compile time.

- `audio.svg`
- `comment.svg`
- `fadeIn.svg`
- `fadeOut.svg`
- `group.svg`
- `midi.svg`
- `notes.svg`
- `osc.svg`
- `pause.svg`
- `play.svg`
- `settings.svg`
- `stop.svg`

All source paths are white on transparent backgrounds. TaSQ rasterizes them at four times the physical display size and applies the required foreground tint at runtime.

The duplicate Settings artwork supplied as `*-1.png` was omitted.
