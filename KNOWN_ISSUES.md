# TaSQ — известные проблемы и ограничения

Этот список отражает известные на момент подготовки Preview 0.9.1 ограничения. Он может меняться по мере тестирования и разработки.

## 1. Dante Virtual Soundcard: высокая многоканальная нагрузка

**Статус: проблема производительности ещё не закрыта.**

В пользовательских тестах с Dante Virtual Soundcard наблюдалось замедление воспроизведения при увеличении количества одновременно работающих Audio Cue.

В последнем описанном тесте:
- 4 Cue субъективно воспроизводились с нормальной скоростью;
- при 15 одновременно работающих Cue замедление сохранялось.

Ранее проблема проявлялась при многоканальной конфигурации DVS. Поэтому высоконагруженное воспроизведение через DVS пока нельзя считать подтверждённо стабильным.

Полноценная проверка физического Dante signal path с подключённым принимающим Dante-устройством не проводилась. Результаты DVS-тестов не следует трактовать как подтверждение всей сетевой цепочки Dante.

**Рекомендация:** до использования DVS на реальном мероприятии проверьте проект на целевой конфигурации, с тем же количеством каналов и одновременно звучащих Cue.

## 2. Sparse Mixer ещё не интегрирован в рабочий Audio Engine

Прототип Sparse Mixer прошёл отдельные тесты на синтетических аудиосигналах. Он пока не используется в обычном воспроизведении TaSQ.

Следовательно:
- Sparse Mixer не исправляет текущую проблему DVS в этой версии;
- его результаты тестирования не являются подтверждением производительности реального ASIO/DVS playback;
- интеграция и аппаратные испытания остаются задачами разработки.

## 3. Межустройственная синхронизация

Синхронизация между независимыми аудиоустройствами с отдельными аппаратными clock sources ещё не реализована как завершённая функция.

Не следует считать, что запуск Cue на разных устройствах гарантирует долговременное совпадение фаз или отсутствие clock drift.

## 4. Совместимость аудиооборудования

TaSQ тестировалась на отдельных Windows-конфигурациях с ASIO, WASAPI и DirectSound. Это не является сертификацией всех аудиоинтерфейсов, драйверов, sample rates, buffer sizes и channel layouts.

Перед использованием на шоу проверьте именно ту конфигурацию, которая будет использоваться на площадке.

## 5. Платформы

Текущая Preview-версия ориентирована на Windows. Готовая macOS-версия в рамках этой версии не заявляется.

## 6. Функции, которых пока нет в Preview

Следующие возможности находятся в разработке или ещё не реализованы:

- Random Playback в Playlist Group;
- Infinite Loop для Playlist Group;
- Crossfade внутри Playlist Group;
- Undo / Redo;
- Waveform Seek без остановки воспроизведения;
- Automatic Silence Trim;
- открытие `.tsq` двойным щелчком через Windows file association;
- Single Instance и передача проекта уже запущенному экземпляру;
- улучшенный запрос имени при Save as Bundle.

Состояние функций: [FEATURES.md](FEATURES.md).

## 7. Как сообщить о новой проблеме

При создании Issue укажите:

1. Версию TaSQ.
2. Версию Windows.
3. Модель аудиоинтерфейса.
4. Тип драйвера и его версию.
5. Sample rate, buffer size и количество выходных каналов.
6. Количество одновременно воспроизводимых Audio Cue.
7. Точные шаги для повторения проблемы.
8. Диагностические логи, если они доступны.

Перед публикацией удалите из логов личные данные, локальные пути и сведения о конфиденциальных проектах.
