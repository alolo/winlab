CueLabs — ASIO / TASCAM US-366 patch

Изменения:
1. Для ASIO-устройства TASCAM US-366 каналы потока 5 и 6 (индексы 4 и 5 в коде)
   отображаются как LINE OUT 1/L и LINE OUT 2/R.
2. Эти два физических выхода показываются первыми в настройках выходов и в списках
   маршрутизации событий.
3. Новые стереособытия при работе через ASIO на US-366 по умолчанию направляются
   на каналы потока 5/6. Уже сохранённые маршруты не перезаписываются.
4. Выбор конфигурации аудиоустройства теперь предпочитает 48 kHz, если драйвер
   предоставляет такой диапазон для максимального числа каналов.
5. Добавлены диагностические сообщения об успешном открытии аудиопотока,
   создании главного окна и первом кадре интерфейса.

Важно:
- Для остальных каналов ASIO 1–4 оставлены нейтральные подписи ASIO Output N,
  потому что точная физическая распиновка этих четырёх каналов не подтверждена.
- Сборка и запуск не проверены в этой среде: Rust/Cargo здесь не установлены.
  Проверить на Windows командой: cargo run
