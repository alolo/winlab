# TaSQ — возможности и состояние функций

Этот документ описывает состояние функций TaSQ для пользователей. Отметка о проверке означает, что функция проходила испытания в конкретных сценариях. Она не является гарантией работы на любом компьютере, аудиоинтерфейсе или драйвере.

## 1. Реализовано и проверено в отдельных сценариях

### Управление Cue и группами

- [x] Создание и воспроизведение Audio Cue.
- [x] Работа с группами событий.
- [x] Режимы Normal, Playlist, All Cues и Timeline.
- [x] Auto-Continue и Auto-Follow на событиях Group в проверенных режимах.
- [x] Выделение следующего события, которое оператор должен запустить вручную, после автоматической цепочки группы.
- [x] Сохранение и повторное открытие тестовых проектов.
- [x] Stop отдельной Cue и Stop All.

### Аудиовоспроизведение

- [x] Одновременное воспроизведение нескольких Audio Cue.
- [x] Infinite Loop для аудиособытий.
- [x] Pause / Resume для отдельных событий и нескольких событий.
- [x] StopFade для плавной остановки; отсутствие слышимых щелчков подтверждено пользователем в проверенных тестах.
- [x] Volume Automation во время воспроизведения.
- [x] Time/Pitch и автоматизация в проверенных сценариях.
- [x] Изменение маршрутизации и уровней во время воспроизведения в проверенных сценариях.
- [x] Глобальная громкость Master Volume с целочисленной шкалой 0–100%.
- [x] Индивидуальный уровень Cue Trim в dB.

### MIDI и OSC

- [x] MIDI Output проверен на Allen & Heath dLive S5000.
- [x] OSC Output проверен с Resolume Arena.

### Аудиодрайверы и оборудование

В пользовательских тестах использовались ASIO, WASAPI и DirectSound, а также несколько аудиоинтерфейсов, включая Focusrite Scarlett 2i2, TASCAM US-4x4, TASCAM US-366, Sound Blaster Omni, Gigaport EX и Dante Virtual Soundcard.

Наличие устройства в списке тестирования не означает, что все его режимы, драйверы и конфигурации полностью проверены.

### Длительный тест Loop

В одном из длительных тестов одновременно воспроизводились 12 Audio Cue на TASCAM US-366 ASIO при 48 kHz и буфере 256 frames. Продолжительность составила около 4 часов 23 минут. В логах зафиксированы 764 общие границы Loop на каждую Cue; application-level PCM prefetch underruns и callback over-budget события в этом тесте не зарегистрированы.

Это результат конкретного теста, а не гарантия аналогичной производительности на любой системе.

## 2. В разработке

Следующие возможности не следует считать доступными в текущей Preview-сборке:

- [ ] **Sparse Mixer** — более эффективное суммирование аудио для многоканальных конфигураций.
- [ ] **До 256 одновременно звучащих Audio Cue на одном endpoint** — целевой показатель будущего движка. Это не реализованный лимит текущей версии и не ограничение общего количества Cue в проекте.
- [ ] **Межустройственная синхронизация** — согласование воспроизведения между независимыми аудиоустройствами.
- [ ] **Playlist Random** — случайный порядок воспроизведения Audio Cue в Playlist Group.
- [ ] **Playlist Group Infinite Loop** — бесконечное повторение содержимого Playlist Group.
- [ ] **Crossfade в Playlist Group** — плавный переход между аудиособытиями.
- [ ] **Undo / Redo** — отмена и повтор изменений проекта.
- [ ] **Waveform Seek во время воспроизведения** — переход к выбранной позиции без остановки Cue.
- [ ] **Automatic Silence Trim** — автоматическое пропускание тишины в начале и конце аудиофайла с возможностью включения и отключения.
- [ ] **Windows file association** — открытие проекта `.tsq` двойным щелчком.
- [ ] **Single Instance** — передача открываемого проекта уже запущенному экземпляру TaSQ.
- [ ] **Улучшение Save as Bundle** — единое имя папки проекта и файла проекта.

## 3. Что пока не заявляется как доступная возможность

- Полноценная межустройственная синхронизация независимых аудиоустройств.
- Гарантированная работа любого количества Cue через Dante Virtual Soundcard.
- Производственный Sparse Mixer.
- macOS-версия.

## 4. Как читать статусы

| Статус | Значение |
|---|---|
| Реализовано и проверено | Функция прошла указанные тестовые сценарии |
| В разработке | Функция запланирована или находится в процессе реализации |
| Не заявляется | Функция пока отсутствует либо её работа не подтверждена |
