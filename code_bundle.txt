    // в”Ђв”Ђ Р—Р°РїСѓСЃРє Рё РґРёСЃРїРµС‚С‡РµСЂРёР·Р°С†РёСЏ РІСЃРµС… С‚РёРїРѕРІ СЃРѕР±С‹С‚РёР№ в”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђ

    fn go(&mut self) {
        let id = match self.selected {
            Some(id) => id,
            None => {
                if let Some(first) = self.cue_list.cues.first() {
                    first.id
                } else {
                    return;
                }
            }
        };
        self.trigger_cue(id);
        self.select_next();
    }

    fn trigger_cue(&mut self, id: Uuid) {
        let Some(cue) = self.cue_list.find_mut(id) else {
            return;
        };

        let pre_wait = cue.pre_wait_secs;
        let post_wait = cue.post_wait_secs;
        let continue_mode = cue.continue_mode.clone();

        if pre_wait > 0.0 {
            cue.state = CueState::Waiting;
            self.pending_triggers.push(PendingTrigger {
                cue_id: id,
                fire_at: Instant::now() + std::time::Duration::from_secs_f64(pre_wait),
                is_pre_wait: true,
            });
            self.status_msg = format!("вЏі Pre-wait ({:.1}s): {}", pre_wait, cue.name);
        } else {
            self.execute_cue_now(id);
        }

        if continue_mode == ContinueMode::AutoContinue {
            if let Some(next_id) = self.next_cue_id(id) {
                let delay = pre_wait + post_wait;
                if delay > 0.0 {
                    self.pending_triggers.push(PendingTrigger {
                        cue_id: next_id,
                        fire_at: Instant::now() + std::time::Duration::from_secs_f64(delay),
                        is_pre_wait: false,
                    });
                } else {
                    self.trigger_cue(next_id);
                }
            }
        }
    }

    fn execute_cue_now(&mut self, id: Uuid) {
        let Some(cue_snapshot) = self.cue_list.find(id).cloned() else {
            return;
        };

        match cue_snapshot.cue_type {
            CueType::Audio => {
                if let Some(c) = self.cue_list.find_mut(id) {
                    c.state = CueState::Playing;
                }
                self.audio.send(AudioCommand::Play {
                    id: cue_snapshot.id,
                    file: cue_snapshot.file_path.clone(),
                    start_secs: cue_snapshot.start_secs,
                    end_secs: cue_snapshot.end_secs,
                    duration_secs: cue_snapshot.duration_secs,
                    volume: cue_snapshot.volume * self.master_vol,
                    fade_in_secs: cue_snapshot.fade_in_secs,
                    fade_out_secs: cue_snapshot.fade_out_secs,
                    fade_curve: cue_snapshot.fade_curve,
                    loop_enabled: cue_snapshot.loop_region.enabled,
                    loop_start: cue_snapshot.loop_region.start_secs,
                    loop_end: cue_snapshot.loop_region.end_secs,
                    loop_count: cue_snapshot.loop_region.count,
                });
                self.report
                    .record(&cue_snapshot.number, &cue_snapshot.name, 0.0, "Play");
                self.status_msg = format!("в–¶ Playing: {}", cue_snapshot.name);
            }

            CueType::Play { target_id } => {
                if let Some(tid) = target_id {
                    self.execute_cue_now(tid);
                } else if !cue_snapshot.file_path.as_os_str().is_empty() {
                    self.audio.send(AudioCommand::Play {
                        id: cue_snapshot.id,
                        file: cue_snapshot.file_path.clone(),
                        start_secs: cue_snapshot.start_secs,
                        end_secs: cue_snapshot.end_secs,
                        duration_secs: cue_snapshot.duration_secs,
                        volume: cue_snapshot.volume * self.master_vol,
                        fade_in_secs: cue_snapshot.fade_in_secs,
                        fade_out_secs: cue_snapshot.fade_out_secs,
                        fade_curve: cue_snapshot.fade_curve,
                        loop_enabled: cue_snapshot.loop_region.enabled,
                        loop_start: cue_snapshot.loop_region.start_secs,
                        loop_end: cue_snapshot.loop_region.end_secs,
                        loop_count: cue_snapshot.loop_region.count,
                    });
                }
                self.check_instant_auto_follow(id);
            }

            CueType::Pause { target_id } => {
                if let Some(tid) = target_id {
                    if let Some(tc) = self.cue_list.find_mut(tid) {
                        tc.state = CueState::Paused;
                    }
                    self.audio.send(AudioCommand::Pause(tid));
                } else {
                    self.pause_all();
                }
                self.check_instant_auto_follow(id);
            }

            CueType::Stop { target_id } => {
                if let Some(tid) = target_id {
                    if let Some(tc) = self.cue_list.find_mut(tid) {
                        tc.state = CueState::Stopped;
                        tc.position_secs = 0.0;
                    }
                    self.audio.send(AudioCommand::Stop(tid));
                } else {
                    self.stop_all();
                }
                self.check_instant_auto_follow(id);
            }

            CueType::Fade {
                target_id,
                fade_in,
                duration_secs,
                stop_on_finish,
            } => {
                if let Some(tid) = target_id {
                    let target_vol = if fade_in {
                        let base = self.cue_list.find(tid).map(|c| c.volume).unwrap_or(1.0);
                        base * self.master_vol
                    } else {
                        0.0
                    };
                    self.audio.send(AudioCommand::Fade {
                        id: tid,
                        target_volume: target_vol,
                        duration_secs,
                        stop_on_finish: !fade_in && stop_on_finish,
                    });
                    self.status_msg = format!("{} ({:.1}s)", cue_snapshot.name, duration_secs);
                }
                if cue_snapshot.continue_mode == ContinueMode::AutoFollow {
                    if let Some(next_id) = self.next_cue_id(id) {
                        self.pending_triggers.push(PendingTrigger {
                            cue_id: next_id,
                            fire_at: Instant::now()
                                + std::time::Duration::from_secs_f64(duration_secs),
                            is_pre_wait: false,
                        });
                    }
                }
            }

            CueType::Midi {
                channel,
                message,
                raw_hex,
            } => {
                let bytes =
                    if !raw_hex.trim().is_empty() && matches!(message, MidiMessageKind::Raw(_)) {
                        MidiMessageKind::parse_hex(&raw_hex)
                    } else {
                        message.to_bytes(channel)
                    };
                let _ = self.midi_out.send_bytes(&bytes);
                self.report
                    .record(&cue_snapshot.number, &cue_snapshot.name, 0.0, "MIDI");
                self.status_msg = format!("рџЋ№ MIDI Sent: {:02X?}", bytes);
                self.check_instant_auto_follow(id);
            }

            CueType::Group {
                mode,
                children,
                fade_in_secs,
                fade_out_secs,
            } => {
                match mode {
                    GroupMode::Normal => {
                        // Р Р°Р·РІРѕСЂР°С‡РёРІР°РµРј РіСЂСѓРїРїСѓ, Р·Р°РїСѓСЃРєР°РµРј С‚РѕР»СЊРєРѕ РїРµСЂРІРѕРіРѕ СЂРµР±С‘РЅРєР°.
                        // Р”Р°Р»СЊС€Рµ С†РµРїРѕС‡РєР° РёРґС‘С‚ СЃР°РјР° РїРѕ auto-continue/auto-follow РґРµС‚РµР№.
                        // РљРѕРіРґР° С†РµРїРѕС‡РєР° РѕР±СЂС‹РІР°РµС‚СЃСЏ (СЂРµР±С‘РЅРѕРє СЃ Nothing) вЂ” РѕРЅ РѕСЃС‚Р°С‘С‚СЃСЏ РІС‹РґРµР»РµРЅРЅС‹Рј.
                        self.expanded_groups.insert(id);
                        if let Some(first_id) = children.first().copied() {
                            self.selected = Some(first_id);
                            self.trigger_cue(first_id);
                            self.status_msg = format!("рџ“Ѓ Group (Normal): starting child");
                        } else {
                            self.status_msg = "рџ“Ѓ Group is empty".to_string();
                        }
                    }
                    GroupMode::Playlist => {
                        // РџРѕСЃР»РµРґРѕРІР°С‚РµР»СЊРЅРѕ РїСЂРѕРёРіСЂС‹РІР°РµРј РІСЃРµС… РґРµС‚РµР№.
                        self.expanded_groups.insert(id);
                        if children.is_empty() {
                            return;
                        }
                        let group_id = cue_snapshot.id;
                        let kids = children.clone();
                        let fi = fade_in_secs;
                        let fo = fade_out_secs;
                        self.start_playlist_child(group_id, kids, 0, fi, fo);
                    }
                }
                self.check_instant_auto_follow(id);
            }
        }
    }

    fn check_instant_auto_follow(&mut self, id: Uuid) {
        if let Some(cue) = self.cue_list.find(id) {
            if cue.continue_mode == ContinueMode::AutoFollow {
                if let Some(next_id) = self.next_cue_id(id) {
                    self.trigger_cue(next_id);
                }
            }
        }
    }

    fn start_playlist_child(
        &mut self,
        group_id: Uuid,
        children: Vec<Uuid>,
        idx: usize,
        fade_in: f64,
        fade_out: f64,
    ) {
        let Some(&child_id) = children.get(idx) else {
            return;
        };

        // РЎРѕС…СЂР°РЅСЏРµРј/РѕР±РЅРѕРІР»СЏРµРј РїСЂРѕРіСЂРµСЃСЃ РїР»РµР№Р»РёСЃС‚Р°
        self.active_playlists.retain(|p| p.group_id != group_id);
        self.active_playlists.push(ActivePlaylist {
            group_id,
            children: children.clone(),
            current_idx: idx,
            fade_in_secs: fade_in,
            fade_out_secs: fade_out,
        });

        // РќР°РєР°С‚С‹РІР°РµРј fade-РЅР°СЃС‚СЂРѕР№РєРё РіСЂСѓРїРїС‹ РЅР° СЂРµР±С‘РЅРєР° РґРѕ Р·Р°РїСѓСЃРєР°
        if let Some(child) = self.cue_list.find_mut(child_id) {
            if fade_in > 0.0 {
                child.fade_in_secs = fade_in;
            }
            if fade_out > 0.0 {
                child.fade_out_secs = fade_out;
            }
        }

        self.selected = Some(child_id);
        self.trigger_cue(child_id);
        self.status_msg = format!("рџ“Ѓ Playlist: child {}/{}", idx + 1, children.len());
    }

    fn handle_drag_drop(&mut self, dragged_id: Uuid, target_idx: usize) {
        // 1) Р•СЃР»Рё С†РµР»СЊ вЂ” РіСЂСѓРїРїР°, РєР»Р°РґС‘Рј С‚СѓРґР° РєР°Рє РІ РїР°РїРєСѓ
        let is_group = self
            .cue_list
            .cues
            .get(target_idx)
            .map(|c| matches!(c.cue_type, CueType::Group { .. }))
            .unwrap_or(false);

        if is_group {
            let group_id = self.cue_list.cues[target_idx].id;
            if dragged_id == group_id {
                return;
            }

            // Р•СЃР»Рё СѓР¶Рµ РІ РєР°РєРѕР№-С‚Рѕ РіСЂСѓРїРїРµ вЂ” РІС‹С‡РёС‰Р°РµРј РёР· СЃС‚Р°СЂРѕР№
            for c in &mut self.cue_list.cues {
                if let CueType::Group { children, .. } = &mut c.cue_type {
                    children.retain(|x| *x != dragged_id);
                }
            }

            // Р”РѕР±Р°РІР»СЏРµРј РІ С†РµР»РµРІСѓСЋ
            if let Some(target) = self.cue_list.cues.get_mut(target_idx) {
                if let CueType::Group { children, .. } = &mut target.cue_type {
                    children.push(dragged_id);
                }
            }
            self.expanded_groups.insert(group_id);
            self.status_msg = "Added cue to group via drag-and-drop".to_string();
            return;
        }

        // 2) РРЅР°С‡Рµ вЂ” РѕР±С‹С‡РЅР°СЏ РїРµСЂРµСЃС‚Р°РЅРѕРІРєР°
        if let Some(from_idx) = self.cue_list.cues.iter().position(|c| c.id == dragged_id) {
            let item = self.cue_list.cues.remove(from_idx);
            let insert_idx = if target_idx > from_idx {
                target_idx - 1
            } else {
                target_idx
            };
            self.cue_list
                .cues
                .insert(insert_idx.min(self.cue_list.cues.len()), item);
            self.cue_list.renumber();
        }
    }

    fn next_cue_id(&self, current_id: Uuid) -> Option<Uuid> {
        let pos = self.cue_list.cues.iter().position(|c| c.id == current_id)?;
        self.cue_list.cues.get(pos + 1).map(|c| c.id)
    }

    fn poll_pending_triggers(&mut self) {
        let now = Instant::now();
        let mut ready = Vec::new();
        self.pending_triggers.retain(|t| {
            if now >= t.fire_at {
                ready.push(t.clone());
                false
            } else {
                true
            }
        });

        for trig in ready {
            if trig.is_pre_wait {
                self.execute_cue_now(trig.cue_id);
            } else {
                self.trigger_cue(trig.cue_id);
            }
        }
    }

    // в”Ђв”Ђ Transport actions в”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђ

    fn stop_selected(&mut self) {
        let id = match self.selected {
            Some(id) => id,
            None => return,
        };
        if let Some(cue) = self.cue_list.find_mut(id) {
            self.report.record(
                &cue.number.clone(),
                &cue.name.clone(),

                "Stop",
            );
            cue.state = CueState::Stopped;
            cue.position_secs = 0.0;
        }
        self.audio.send(AudioCommand::Stop(id));
        self.status_msg = "вЏ№ Stopped".to_string();
    }

    fn stop_all(&mut self) {
        self.pending_triggers.clear();
        self.cue_list.stop_all();
        self.audio.send(AudioCommand::StopAll);
        self.status_msg = "вЏ№ All stopped".to_string();
    }

    fn pause_selected(&mut self) {
        let id = match self.selected {
            Some(id) => id,
            None => return,
        };
        if let Some(cue) = self.cue_list.find_mut(id) {
            cue.state = CueState::Paused;
            self.audio.send(AudioCommand::Pause(id));
            self.report.record(
                &cue.number.clone(),
                &cue.name.clone(),
                cue.position_secs,
                "Pause",
            );
        }
    }

    fn pause_all(&mut self) {
        self.cue_list.pause_all();
        self.audio.send(AudioCommand::PauseAll);
        self.status_msg = "вЏё All paused".to_string();
    }

    fn resume_selected(&mut self) {
        let id = match self.selected {
            Some(id) => id,
            None => return,
        };
        if let Some(cue) = self.cue_list.find_mut(id) {
            cue.state = CueState::Playing;
            self.audio.send(AudioCommand::Resume(id));
            self.report.record(
                &cue.number.clone(),
                &cue.name.clone(),
                cue.position_secs,
                "Resume",
            );
        }
    }

    fn resume_all(&mut self) {
        self.cue_list.resume_all();
        self.audio.send(AudioCommand::ResumeAll);
        self.status_msg = "в–¶ All resumed".to_string();
    }

    // в”Ђв”Ђ РЎРѕР·РґР°РЅРёРµ Рё СѓРїСЂР°РІР»РµРЅРёРµ СЃРѕР±С‹С‚РёСЏРјРё в”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђ

    fn add_files(&mut self) {
        let files = FileDialog::new()
            .add_filter(
                "Audio",
                &["wav", "mp3", "flac", "ogg", "aiff", "aif", "m4a"],
            )
            .pick_files();

        if let Some(paths) = files {
            for path in paths {
                self.import_file(path);
            }
        }
    }

    fn import_file(&mut self, path: PathBuf) {
        let final_path = if self.project_path.is_some() {
            self.assets
                .import_file(&path)
                .unwrap_or_else(|_| path.clone())
        } else {
            path.clone()
        };

        let mut cue = Cue::new_audio(final_path.clone());
        let dur = get_duration(&final_path);
        if dur > 0.0 {
            cue.duration_secs = dur;
            cue.loop_region.end_secs = dur;
        }
        cue.waveform = generate_waveform(&final_path, 512);

        let name = cue.name.clone();
        self.cue_list.add(cue);
        self.selected = self.cue_list.cues.last().map(|c| c.id);
        self.status_msg = format!("Added audio cue: {name}");
    }

    fn add_typed_cue(&mut self, cue_type: CueType) {
        let is_midi = matches!(&cue_type, CueType::Midi { .. });
        let cue = Cue::new_typed(cue_type);
        let label = cue.name.clone();
        self.cue_list.add(cue);
        self.selected = self.cue_list.cues.last().map(|c| c.id);
        if is_midi {
            self.active_panel = Panel::Midi;
        } else {
            self.active_panel = Panel::Inspector;
        }
        self.status_msg = format!("Added {label} event");
    }

    fn delete_cue(&mut self, id: Uuid) {
        self.audio.send(AudioCommand::Stop(id));
        if self.selected == Some(id) {
            self.selected = None;
        }
        // РЈР±РёСЂР°РµРј id РёР· РІСЃРµС… РіСЂСѓРїРї
        for c in &mut self.cue_list.cues {
            if let CueType::Group { children, .. } = &mut c.cue_type {
                children.retain(|x| *x != id);
            }
        }
        self.cue_list.remove(id);
        self.expanded_groups.remove(&id);
        self.active_playlists.retain(|p| p.group_id != id);
    }

    fn select_next(&mut self) {
        if self.cue_list.cues.is_empty() {
            return;
        }
        self.selected = Some(match self.selected {
            None => self.cue_list.cues[0].id,
            Some(cur) => {
                let pos = self
                    .cue_list
                    .cues
                    .iter()
                    .position(|c| c.id == cur)
                    .unwrap_or(0);
                self.cue_list.cues[(pos + 1).min(self.cue_list.cues.len() - 1)].id
            }
        });
    }

    fn select_prev(&mut self) {
        if self.cue_list.cues.is_empty() {
            return;
        }
        self.selected = Some(match self.selected {
            None => self.cue_list.cues[0].id,
            Some(cur) => {
                let pos = self
                    .cue_list
                    .cues
                    .iter()
                    .position(|c| c.id == cur)
                    .unwrap_or(0);
                self.cue_list.cues[pos.saturating_sub(1)].id
            }
        });
    }

    fn save_project(&mut self) {
        if self.project_path.is_none() {
            let path = FileDialog::new()
                .add_filter("CueLabs Project", &["clabs"])
                .save_file();
            match path {
                Some(p) => {

                        p.with_extension("clabs")
                    } else {
                        p

                    self.assets.set_project_path(p.clone());

                }
                None => return,

        let path = self.project_path.clone().unwrap();
        self.project.cue_list = self.cue_list.clone();

        match self.project.save(&path) {
            Ok(_) => self.status_msg = format!("рџ’ѕ Saved: {}", path.display()),
            Err(e) => {
                self.status_msg = format!("Save error: {e}");
                error!("{e}");
            }
        }
    }

    fn open_project(&mut self) {
        self.stop_all();

        let file = FileDialog::new()
            .add_filter("CueLabs Project", &["clabs"])
            .pick_file();

        if let Some(path) = file {
            match Project::load(&path) {
                Ok(proj) => {
                    let mut cl = proj.cue_list.clone();
                    for cue in &mut cl.cues {
                        if !cue.file_path.as_os_str().is_empty() {
                            if cue.duration_secs == 0.0 {
                                let d = get_duration(&cue.file_path);
                                if d > 0.0 {
                                    cue.duration_secs = d;
                                }
                            }
                            if cue.waveform.is_empty() {
                                cue.waveform = generate_waveform(&cue.file_path, 512);
                            }
                        }
                    }

                    self.cue_list = cl;
                    self.assets.set_project_path(path.clone());
                    self.project_path = Some(path.clone());
                    self.report = SessionReport::new(&proj.settings.name);
                    self.project = proj;
                    self.selected = None;
                    self.status_msg = format!("рџ“‚ Opened: {}", path.display());
                }
                Err(e) => {
                    self.status_msg = format!("Open error: {e}");
                    error!("{e}");
                }
            }
        }
    }

    fn poll_audio(&mut self) {
        let mut finished_auto_follow = Vec::new();
        // (group_id, child_id) вЂ” РєР°РєРёРµ РґРµС‚Рё Р·Р°РІРµСЂС€РёР»РёСЃСЊ, С‡С‚РѕР±С‹ РїСЂРѕРґРІРёРЅСѓС‚СЊ РїР»РµР№Р»РёСЃС‚
        let mut finished_playlist_child: Vec<(Uuid, Uuid)> = Vec::new();

        for upd in self.audio.drain_position_updates() {
            if let Some(cue) = self.cue_list.find_mut(upd.id) {
                let was_active = cue.is_active();
                cue.state = upd.state.clone();
                cue.position_secs = upd.position_secs;
                if upd.state == CueState::Stopped {
                    cue.position_secs = 0.0;
                    if was_active {
                        if cue.continue_mode == ContinueMode::AutoFollow {
                            finished_auto_follow.push(upd.id);
                        }
                        // РџСЂРѕРІРµСЂСЏРµРј, СЏРІР»СЏРµС‚СЃСЏ Р»Рё СЌС‚РѕС‚ СЂРµР±С‘РЅРѕРє С‚РµРєСѓС‰РёРј РІ РєР°РєРѕРј-С‚Рѕ РїР»РµР№Р»РёСЃС‚Рµ
                        for pl in &self.active_playlists {
                            if pl.children.get(pl.current_idx) == Some(&upd.id) {
                                finished_playlist_child.push((pl.group_id, upd.id));
                            }
                        }
                    }
                }
            }
        }

        for fin_id in finished_auto_follow {
            if let Some(next_id) = self.next_cue_id(fin_id) {
                self.trigger_cue(next_id);
            }
        }

        for (group_id, _child) in finished_playlist_child {
            if let Some(pos) = self
                .active_playlists
                .iter()
                .position(|p| p.group_id == group_id)
            {
                let mut pl = self.active_playlists.remove(pos);
                pl.current_idx += 1;
                if pl.current_idx < pl.children.len() {
                    let next_idx = pl.current_idx;
                    let fi = pl.fade_in_secs;
                    let fo = pl.fade_out_secs;
                    let kids = pl.children.clone();
                    self.start_playlist_child(group_id, kids, next_idx, fi, fo);
                } else {
                    self.status_msg = "рџ“Ѓ Playlist finished".to_string();
                }
            }
        }
    }

    fn poll_midi(&mut self) {
        for msg in self.midi.drain() {
            use crate::midi::input::MidiMessage;
            match msg {
                MidiMessage::NoteOn {
                    channel: _,
                    note,
                    velocity: _,
                } => {
                    if let Some(cue_id) = self
                        .cue_list
                        .cues
                        .iter()
                        .find(|c| {
                            matches!(
                                &c.midi_trigger,
                                Some(crate::cue::MidiTrigger::NoteOn { note: n, .. }) if *n == note
                            )
                        })
                        .map(|c| c.id)
                    {
                        self.trigger_cue(cue_id);
                    }
                }
                MidiMessage::CC {
                    channel: _,
                    cc,
                    value,
                } => {
                    if cc == 7 {
                        let vol = value as f32 / 127.0;
                        self.master_vol = vol;
                        for cue in self.cue_list.cues.iter().filter(|c| c.is_active()) {
                            self.audio
                                .send(AudioCommand::SetVolume(cue.id, cue.volume * vol));
                        }
                    }
                }
                _ => {}
            }
        }
    }

    fn poll_osc(&mut self) {
        let events = match &self.osc {
            Some(osc) => osc.drain(),
            None => return,
        };
        for ev in events {
            match ev.addr.as_str() {
                "/go" | "/cue/go" => self.go(),
                "/stop" | "/cue/stop" => self.stop_all(),
                "/pause" | "/cue/pause" => self.pause_all(),
                "/resume" | "/cue/resume" => self.resume_all(),
                _ => {}
            }
        }
    }

    // в”Ђв”Ђ Р“РѕСЂСЏС‡РёРµ РєР»Р°РІРёС€Рё Рё Drag-and-drop в”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђ

    fn handle_keyboard(&mut self, ctx: &Context) {
        if ctx.memory(|m| m.focused().is_some()) {
            return;
        }

        let keys: Vec<(Key, bool, bool, bool)> = ctx.input(|inp| {
            let mut v = Vec::new();
            for &k in &[
                Key::Space,
                Key::S,
                Key::Escape,
                Key::P,
                Key::R,
                Key::ArrowDown,
                Key::ArrowUp,
                Key::Delete,
                Key::N,
                Key::O,
                Key::I,
            ] {
                if inp.key_pressed(k) {
                    v.push((
                        k,
                        inp.modifiers.ctrl,
                        inp.modifiers.shift,
                        inp.modifiers.alt,
                    ));
                }
            }
            v
        });

        for (key, ctrl, shift, alt) in keys {
            match (key, ctrl, shift, alt) {
                (Key::Space, false, false, false) => self.go(),
                (Key::S, false, false, false) => self.stop_selected(),
                (Key::Escape, false, false, false) => self.stop_all(),
                (Key::P, false, false, false) => self.pause_selected(),
                (Key::P, false, true, false) => self.pause_all(),
                (Key::R, false, false, false) => self.resume_selected(),
                (Key::R, false, true, false) => self.resume_all(),
                (Key::ArrowDown, false, false, false) => self.select_next(),
                (Key::ArrowUp, false, false, false) => self.select_prev(),
                (Key::Delete, false, false, false) => {
                    if let Some(id) = self.selected {
                        self.delete_cue(id);
                    }
                }
                (Key::S, true, false, false) => self.save_project(),
                (Key::O, true, false, false) => self.open_project(),
                (Key::N, true, false, false) => self.new_project(),
                (Key::I, true, false, false) => self.add_files(),
                _ => {}
            }
        }
    }

    fn handle_drop(&mut self, ctx: &Context) {
        // dropped_files Р¶РёРІС‘С‚ СЂРѕРІРЅРѕ РѕРґРёРЅ РєР°РґСЂ вЂ” РєР»РѕРЅРёСЂСѓРµРј РЎР РђР—РЈ, РґРѕ Р»СЋР±С‹С… РґРµР№СЃС‚РІРёР№
        let dropped: Vec<PathBuf> = ctx.input(|i| {
            i.raw
                .dropped_files
                .iter()
                .filter_map(|f| f.path.clone())
                .collect()
        });
        if dropped.is_empty() {
            return;
        }

        let audio_exts = ["wav", "mp3", "flac", "ogg", "aiff", "aif", "m4a"];
        let mut added = 0;
        for path in dropped {
            let is_audio = path
                .extension()
                .and_then(|e| e.to_str())
                .map(|e| audio_exts.contains(&e.to_lowercase().as_str()))
                .unwrap_or(false);
            if !is_audio {
                tracing::warn!("Dropped non-audio file ignored: {:?}", path);
                continue;
            }
            tracing::info!("Dropped audio file: {:?}", path);
            self.import_file(path);
            added += 1;
        }

        if added > 0 {
            ctx.request_repaint();
            self.status_msg = format!("Added {} file(s) via drag-and-drop", added);
        }
    }

#[derive(Debug, Clone)]
pub struct PositionUpdate {
    pub id: Uuid,
    pub position_secs: f64,
    pub state: CueState,

pub struct AudioEngine {
    pub cmd_tx: Sender<AudioCommand>,
    pub pos_rx: Receiver<PositionUpdate>,
    pub output_devices: Vec<String>,
    pub input_devices: Vec<String>,
    pub current_device: String,
    pub current_input_device: String,
}

impl AudioEngine {
    pub fn new() -> Result<Self> {
        let host = cpal::default_host();
        let output_devices = Self::list_output_devices(&host);
        let input_devices = Self::list_input_devices(&host);

        let out_dev = host
            .default_output_device()
            .ok_or_else(|| anyhow::anyhow!("No output audio device found"))?;
        let out_name = out_dev.name().unwrap_or_else(|_| "Default Output".to_string());

        let in_name = host
            .default_input_device()
            .and_then(|d| d.name().ok())
            .unwrap_or_else(|| "Default Input".to_string());

        info!("Audio Output: {}, Input: {}", out_name, in_name);

        let (cmd_tx, cmd_rx) = bounded::<AudioCommand>(256);
        let (pos_tx, pos_rx) = bounded::<PositionUpdate>(1024);

        std::thread::spawn(move || {
            audio_worker(out_dev, cmd_rx, pos_tx);
        });

        Ok(Self {
            cmd_tx,
            pos_rx,
            output_devices,
            input_devices,
            current_device: out_name,
            current_input_device: in_name,
        })
    }

    fn list_output_devices(host: &Host) -> Vec<String> {
        host.output_devices()
            .map(|devs| devs.filter_map(|d| d.name().ok()).collect())
            .unwrap_or_default()
    }

    fn list_input_devices(host: &Host) -> Vec<String> {
        host.input_devices()
            .map(|devs| devs.filter_map(|d| d.name().ok()).collect())
            .unwrap_or_default()
    }

    pub fn set_output_device(&mut self, name: &str) {
        self.current_device = name.to_string();
        self.send(AudioCommand::SetOutputDevice(name.to_string()));
    }

    pub fn set_input_device(&mut self, name: &str) {
        self.current_input_device = name.to_string();
        self.send(AudioCommand::SetInputDevice(name.to_string()));
    }

    pub fn send(&self, cmd: AudioCommand) {
        if let Err(e) = self.cmd_tx.send(cmd) {
            error!("Failed to send audio command: {}", e);
        }
    }

    pub fn drain_position_updates(&self) -> Vec<PositionUpdate> {
        let mut updates = Vec::new();
        while let Ok(u) = self.pos_rx.try_recv() {
            updates.push(u);
        }
        updates
    }
}

struct ActivePlayer {
    id: Uuid,
    file: PathBuf,
    sink: rodio::Sink,
    start_secs: f64,
    end_secs: f64,
    base_volume: f32,
    current_volume: f32,

impl ActivePlayer {
    fn current_pos(&self) -> f64 {
        if let Some(p) = self.paused_at {
            p
        } else {
            self.segment_start_pos + self.segment_instant.elapsed().as_secs_f64()
        }
    }
}

fn open_sink_at(
    stream_handle: &rodio::OutputStreamHandle,
    file_path: &PathBuf,
    offset_secs: f64,
    initial_vol: f32,
) -> Option<rodio::Sink> {
    let file = std::fs::File::open(file_path).ok()?;
    let sink = rodio::Sink::try_new(stream_handle).ok()?;
    let decoder = rodio::Decoder::new(std::io::BufReader::new(file)).ok()?;
    sink.set_volume(initial_vol);
    if offset_secs > 0.0 {
        sink.append(decoder.skip_duration(Duration::from_secs_f64(offset_secs)));
    } else {
        sink.append(decoder);
    }
    sink.play();
    Some(sink)
}

fn audio_worker(
    initial_device: Device,
    cmd_rx: Receiver<AudioCommand>,
    pos_tx: Sender<PositionUpdate>,
) {
    let mut current_stream = rodio::OutputStream::try_from_device(&initial_device).ok();
    if current_stream.is_none() {
        error!("Could not open initial audio output stream");
        return;
    }

    let mut players: Vec<ActivePlayer> = Vec::new();
    let tick = Duration::from_millis(20);

    loop {
        while let Ok(cmd) = cmd_rx.try_recv() {
            match cmd {
                AudioCommand::SetOutputDevice(dev_name) => {
                    let host = cpal::default_host();
                    if let Ok(mut devs) = host.output_devices() {
                        if let Some(dev) = devs.find(|d| d.name().ok().as_deref() == Some(&dev_name))
                        {
                            for p in &players {
                                p.sink.stop();
                            }
                            players.clear();
                            if let Ok(new_stream) = rodio::OutputStream::try_from_device(&dev) {
                                current_stream = Some(new_stream);
                                info!("Switched output audio device to: {}", dev_name);
                            }
                        }
                    }
                }
                AudioCommand::SetInputDevice(dev_name) => {
                    info!("Selected input audio device: {}", dev_name);
                }
                other => {
                    if let Some((_, ref handle)) = current_stream {
                        handle_command(other, handle, &mut players);
                    }
                }
            }
        }

        let mut finished_ids = Vec::new();

        if let Some((_, ref handle)) = current_stream {
            for p in &mut players {
                if p.sink.is_paused() {
                    let _ = pos_tx.try_send(PositionUpdate {
                        id: p.id,
                        position_secs: p.current_pos(),
                        state: CueState::Paused,
                    });
                    continue;
                }

                let mut pos = p.current_pos();

                // РџСЂРѕРІРµСЂРєР° С†РёРєР»Р° (Loop)
                let valid_loop = p.loop_enabled && p.loop_end > p.loop_start;
                if valid_loop && pos >= p.loop_end {
                    if p.loops_remaining == -1 || p.loops_remaining > 1 {
                        if p.loops_remaining > 1 {
                            p.loops_remaining -= 1;
                        }
                        p.sink.stop();
                        if let Some(new_sink) =
                            open_sink_at(handle, &p.file, p.loop_start, p.current_volume)
                        {
                            p.sink = new_sink;
                            p.segment_start_pos = p.loop_start;
                            p.segment_instant = Instant::now();
                            pos = p.loop_start;
                        } else {
                            finished_ids.push(p.id);
                            continue;
                        }
                    }
                }

                // РџСЂРѕРІРµСЂРєР° С‚РѕС‡РєРё РѕРєРѕРЅС‡Р°РЅРёСЏ (Custom End Point РёР»Рё РєРѕРЅРµС† С„Р°Р№Р»Р°)
                if (p.end_secs > 0.0 && pos >= p.end_secs) || p.sink.empty() {
                    p.sink.stop();
                    finished_ids.push(p.id);
                    continue;
                }

                // Р Р°СЃС‡РµС‚ РѕРіРёР±Р°СЋС‰РµР№ РіСЂРѕРјРєРѕСЃС‚Рё (Fade In / Fade Out / Dynamic Fade)
                let mut state = CueState::Playing;
                let mut env = 1.0_f32;

                let elapsed_from_start = (pos - p.start_secs).max(0.0);
                if p.fade_in_secs > 0.0 && elapsed_from_start < p.fade_in_secs {
                    let t = (elapsed_from_start / p.fade_in_secs) as f32;
                    env *= p.fade_curve.apply(t);
                    state = CueState::FadingIn;
                }

                if p.end_secs > 0.0 && p.fade_out_secs > 0.0 {
                    let remaining = (p.end_secs - pos).max(0.0);
                    if remaining < p.fade_out_secs {
                        let t = (remaining / p.fade_out_secs) as f32;
                        env *= p.fade_curve.apply(t);
                        state = CueState::FadingOut;
                    }
                }

                if let Some(ref df) = p.dynamic_fade {
                    let df_elapsed = df.start_time.elapsed().as_secs_f64();
                    if df_elapsed >= df.duration_secs {
                        p.base_volume = df.target_vol;
                        let should_stop = df.stop_on_finish;
                        p.dynamic_fade = None;
                        if should_stop {
                            p.sink.stop();
                            finished_ids.push(p.id);
                            continue;
                        }
                    } else {
                        let t = (df_elapsed / df.duration_secs.max(0.001)) as f32;
                        let interp = df.start_vol + (df.target_vol - df.start_vol) * t;
                        p.current_volume = interp * env;
                        p.sink.set_volume(p.current_volume);
                        state = if df.target_vol >= df.start_vol {
                            CueState::FadingIn
                        } else {
                            CueState::FadingOut
                        };
                        let _ = pos_tx.try_send(PositionUpdate {
                            id: p.id,
                            position_secs: pos,
                            state,
                        });
                        continue;
                    }
                }

                p.current_volume = p.base_volume * env;
                p.sink.set_volume(p.current_volume);

                let _ = pos_tx.try_send(PositionUpdate {
                    id: p.id,
                    position_secs: pos,
                    state,
                });
            }
        }

        for fin_id in finished_ids {
            players.retain(|p| p.id != fin_id);
            let _ = pos_tx.try_send(PositionUpdate {
                id: fin_id,
                position_secs: 0.0,
                state: CueState::Stopped,
            });
        }

        std::thread::sleep(tick);
    }
}

fn handle_command(
    cmd: AudioCommand,
    stream_handle: &rodio::OutputStreamHandle,
    players: &mut Vec<ActivePlayer>,
) {
    match cmd {
        AudioCommand::Play {
            id,
            file,
            start_secs,
            end_secs,
            duration_secs,
            volume,
            fade_in_secs,
            fade_out_secs,
            fade_curve,
            loop_enabled,
            loop_start,
            loop_end,
            loop_count,
        } => {
            players.retain(|p| {
                if p.id == id {
                    p.sink.stop();
                    false
                } else {
                    true
                }
            });

            let initial_vol = if fade_in_secs > 0.0 { 0.0 } else { volume };
            let Some(sink) = open_sink_at(stream_handle, &file, start_secs, initial_vol) else {
                warn!("Cannot open audio file for playback: {:?}", file);
                return;
            };

            let eff_end = end_secs
                .unwrap_or(duration_secs)
                .min(if duration_secs > 0.0 { duration_secs } else { f64::MAX });

            let l_end = if loop_end > loop_start {
                loop_end
            } else {
                eff_end
            };

            players.push(ActivePlayer {
                id,
                file,
                sink,
                start_secs,
                end_secs: if eff_end == f64::MAX { 0.0 } else { eff_end },
                base_volume: volume,
                current_volume: initial_vol,
                fade_in_secs,
                fade_out_secs,
                fade_curve,
                loop_enabled,
                loop_start,
                loop_end: l_end,
                loops_remaining: loop_count,
                segment_start_pos: start_secs,
                segment_instant: Instant::now(),
                paused_at: None,
                dynamic_fade: None,
            });
        }

        AudioCommand::Stop(id) => {
            if let Some(p) = players.iter().find(|p| p.id == id) {
                p.sink.stop();
            }
            players.retain(|p| p.id != id);
        }

        AudioCommand::StopAll => {
            for p in players.iter() {
                p.sink.stop();
            }
            players.clear();
        }

        AudioCommand::Pause(id) => {
            if let Some(p) = players.iter_mut().find(|p| p.id == id) {
                let pos = p.current_pos();
                p.sink.pause();
                p.paused_at = Some(pos);
            }
        }

        AudioCommand::PauseAll => {
            for p in players.iter_mut() {
                let pos = p.current_pos();
                p.sink.pause();
                p.paused_at = Some(pos);
            }
        }

        AudioCommand::Resume(id) => {
            if let Some(p) = players.iter_mut().find(|p| p.id == id) {
                if let Some(pos) = p.paused_at.take() {
                    p.segment_start_pos = pos;
                    p.segment_instant = Instant::now();
                }
                p.sink.play();
            }
        }

        AudioCommand::ResumeAll => {
            for p in players.iter_mut() {
                if let Some(pos) = p.paused_at.take() {
                    p.segment_start_pos = pos;
                    p.segment_instant = Instant::now();
                }
                p.sink.play();
            }
        }

        AudioCommand::SetVolume(id, vol) => {
            if let Some(p) = players.iter_mut().find(|p| p.id == id) {
                p.base_volume = vol;
                p.sink.set_volume(vol);
            }
        }

        AudioCommand::Fade {
            id,
            target_volume,
            duration_secs,
            stop_on_finish,
        } => {
            if let Some(p) = players.iter_mut().find(|p| p.id == id) {
                p.dynamic_fade = Some(DynamicFade {
                    start_vol: p.current_volume,
                    target_vol: target_volume,
                    start_time: Instant::now(),
                    duration_secs,
                    stop_on_finish,
                });
            }
        }

        AudioCommand::SetOutputDevice(_) | AudioCommand::SetInputDevice(_) => {}
    }
}

use rodio::Source;
use std::path::Path;
use tracing::{debug, error};

/// РЎР¶РёРјР°РµС‚ Р°СѓРґРёРѕС„Р°Р№Р» РІ РјР°СЃСЃРёРІ РїР°СЂ [min, max] РґР»СЏ РѕС‚СЂРёСЃРѕРІРєРё РІРµР№РІС„РѕСЂРјС‹
pub fn generate_waveform(path: &Path, buckets: usize) -> Vec<f32> {
    if path.as_os_str().is_empty() {
        return vec![];
    }
    let file = match std::fs::File::open(path) {
        Ok(f) => f,
        Err(e) => {
            error!("Waveform: cannot open {:?}: {e}", path);
            return vec![0.0; buckets * 2];
        }
    };

    let decoder = match rodio::Decoder::new(std::io::BufReader::new(file)) {
        Ok(d) => d,
        Err(e) => {
            error!("Waveform: decode error {:?}: {e}", path);
            return vec![0.0; buckets * 2];
        }
    };

    let samples: Vec<f32> = decoder.map(|s| s as f32 / i16::MAX as f32).collect();

    if samples.is_empty() {
        return vec![0.0; buckets * 2];
    }

    let bucket_size = (samples.len() / buckets).max(1);
    let mut result = Vec::with_capacity(buckets * 2);

    for i in 0..buckets {
        let start = i * bucket_size;
        let end = ((i + 1) * bucket_size).min(samples.len());
        if start >= samples.len() {
            result.push(0.0);
            result.push(0.0);
            continue;
        }
        let slice = &samples[start..end];
        let min = slice.iter().copied().fold(f32::INFINITY, f32::min);
        let max = slice.iter().copied().fold(f32::NEG_INFINITY, f32::max);
        result.push(min.clamp(-1.0, 0.0));
        result.push(max.clamp(0.0, 1.0));
    }

    debug!("Waveform generated: {} buckets for {:?}", buckets, path);
    result
}

/// РўРѕС‡РЅРѕРµ РѕРїСЂРµРґРµР»РµРЅРёРµ РґР»РёС‚РµР»СЊРЅРѕСЃС‚Рё Р°СѓРґРёРѕС„Р°Р№Р»Р° СЃ СѓС‡РµС‚РѕРј С‡РёСЃР»Р° РєР°РЅР°Р»РѕРІ Рё С‡Р°СЃС‚РѕС‚С‹ РґРёСЃРєСЂРµС‚РёР·Р°С†РёРё
pub fn get_duration(path: &Path) -> f64 {
    if path.as_os_str().is_empty() {
        return 0.0;
    }
    let file = match std::fs::File::open(path) {
        Ok(f) => f,
        Err(_) => return 0.0,
    };
    match rodio::Decoder::new(std::io::BufReader::new(file)) {
        Ok(d) => {
            if let Some(dur) = d.total_duration() {
                return dur.as_secs_f64();
            }
            let channels = d.channels().max(1) as f64;
            let rate = d.sample_rate().max(1) as f64;
            let total_samples = d.count() as f64;
            total_samples / (channels * rate)
        }
        Err(_) => 0.0,
    }
}

    NoteOff { note: u8, velocity: u8 },

impl MidiMessageKind {
    pub fn label(&self) -> &'static str {
        match self {
            MidiMessageKind::NoteOn { .. } => "Note On",
            MidiMessageKind::NoteOff { .. } => "Note Off",
            MidiMessageKind::ControlChange { .. } => "Control Change",
            MidiMessageKind::ProgramChange { .. } => "Program Change",
            MidiMessageKind::PitchBend { .. } => "Pitch Bend",
            MidiMessageKind::Raw(_) => "Raw MIDI Code",
        }
    }

    pub fn to_bytes(&self, channel: u8) -> Vec<u8> {
        let ch = channel.saturating_sub(1) & 0x0F;
        match self {
            MidiMessageKind::NoteOn { note, velocity } => vec![0x90 | ch, *note & 0x7F, *velocity & 0x7F],
            MidiMessageKind::NoteOff { note, velocity } => vec![0x80 | ch, *note & 0x7F, *velocity & 0x7F],
            MidiMessageKind::ControlChange { cc, value } => vec![0xB0 | ch, *cc & 0x7F, *value & 0x7F],
            MidiMessageKind::ProgramChange { program } => vec![0xC0 | ch, *program & 0x7F],
            MidiMessageKind::PitchBend { value } => {
                let v = (*value + 8192).clamp(0, 16383) as u16;
                vec![0xE0 | ch, (v & 0x7F) as u8, ((v >> 7) & 0x7F) as u8]
            }
            MidiMessageKind::Raw(b) => b.clone(),
        }
    }

    pub fn parse_hex(hex_str: &str) -> Vec<u8> {
        hex_str
            .split(|c: char| c.is_whitespace() || c == ',' || c == ';')
            .filter(|s| !s.is_empty())
            .filter_map(|s| {
                let clean = s.strip_prefix("0x").or_else(|| s.strip_prefix("0X")).unwrap_or(s);
                u8::from_str_radix(clean, 16).ok()
            })
            .collect()
    }
}

        let t = t.clamp(0.0, 1.0);
        match self {
            FadeCurve::Linear => t,
            FadeCurve::SCurve => t * t * (3.0 - 2.0 * t),

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub enum MidiMessage {
    NoteOn { channel: u8, note: u8, velocity: u8 },
    NoteOff { channel: u8, note: u8 },
    CC { channel: u8, cc: u8, value: u8 },
    SysEx(Vec<u8>),
}

pub struct MidiInputManager {
    pub msg_rx: Receiver<MidiMessage>,
    pub port_names: Vec<String>,
    _connection: Option<MidiInputConnection<()>>,
}

impl MidiInputManager {
    pub fn new() -> Self {
        let (tx, rx) = bounded::<MidiMessage>(512);
        let (port_names, conn) = Self::try_connect(tx);
        Self {
            msg_rx: rx,
            port_names,
            _connection: conn,
        }
    }

    fn try_connect(tx: Sender<MidiMessage>) -> (Vec<String>, Option<MidiInputConnection<()>>) {
        let midi_in = match MidiInput::new("CueLabs Input") {
            Ok(m) => m,
            Err(e) => {
                warn!("MIDI init failed: {e}");
                return (vec![], None);
            }
        };

        let ports = midi_in.ports();
        let names: Vec<String> = ports
            .iter()
            .filter_map(|p| midi_in.port_name(p).ok())
            .collect();

        let port = match ports.first() {
            Some(p) => p.clone(),
            None => return (names, None),
        };

        let conn = midi_in
            .connect(
                &port,
                "cuelabs-in",
                move |_stamp, raw, _| {
                    if let Some(msg) = parse_midi(raw) {
                        let _ = tx.try_send(msg);
                    }
                },
                (),
            )
            .ok();

        (names, conn)
    }

    pub fn drain(&self) -> Vec<MidiMessage> {
        let mut out = Vec::new();
        while let Ok(m) = self.msg_rx.try_recv() {
            out.push(m);
        }
        out
    }
}

pub struct MidiOutputManager {
    pub port_names: Vec<String>,
    pub current_port: Option<String>,
    connection: Option<MidiOutputConnection>,
}

impl MidiOutputManager {
    pub fn new() -> Self {
        let mut mgr = Self {
            port_names: Vec::new(),
            current_port: None,
            connection: None,
        };
        mgr.refresh_and_connect(None);
        mgr
    }

    pub fn refresh_and_connect(&mut self, preferred_port: Option<&str>) {
        let Ok(midi_out) = MidiOutput::new("CueLabs Output") else {
            return;
        };
        let ports = midi_out.ports();
        self.port_names = ports
            .iter()
            .filter_map(|p| midi_out.port_name(p).ok())
            .collect();

        let target_port = if let Some(pref) = preferred_port {
            ports
                .iter()
                .find(|p| midi_out.port_name(p).ok().as_deref() == Some(pref))
                .or_else(|| ports.first())
        } else {
            ports.first()
        };

        if let Some(p) = target_port {
            let pname = midi_out.port_name(p).unwrap_or_default();
            if let Ok(conn) = midi_out.connect(p, "cuelabs-out") {
                info!("Connected MIDI Output: {}", pname);
                self.current_port = Some(pname);
                self.connection = Some(conn);
            }
        }
    }

    pub fn send_bytes(&mut self, bytes: &[u8]) -> anyhow::Result<()> {
        if bytes.is_empty() {
            return Ok(());
        }
        if let Some(ref mut conn) = self.connection {
            conn.send(bytes)
                .map_err(|e| anyhow::anyhow!("MIDI send error: {e}"))?;
        } else {
            warn!("No MIDI Output port connected; bytes {:02X?} not sent", bytes);
        }
        Ok(())
    }
}

fn parse_midi(raw: &[u8]) -> Option<MidiMessage> {
    if raw.is_empty() {
        return None;
    }
    let status = raw[0];
    let kind = status & 0xF0;
    let channel = status & 0x0F;

    match kind {
        0x90 if raw.len() >= 3 && raw[2] > 0 => Some(MidiMessage::NoteOn {
            channel,
            note: raw[1],
            velocity: raw[2],
        }),
        0x80 | 0x90 if raw.len() >= 3 => Some(MidiMessage::NoteOff {
            channel,
            note: raw[1],
        }),
        0xB0 if raw.len() >= 3 => Some(MidiMessage::CC {
            channel,
            cc: raw[1],
            value: raw[2],
        }),
        0xF0 => Some(MidiMessage::SysEx(raw.to_vec())),
        _ => None,
    }
}

use anyhow::Result;
use crossbeam_channel::{bounded, Receiver, Sender};
use rosc::{OscMessage, OscPacket, OscType};
use std::net::UdpSocket;
use tracing::{error, info, warn};

#[derive(Debug, Clone)]
pub struct OscEvent {
    pub addr: String,
    pub args: Vec<OscType>,
}

#[allow(dead_code)]
pub struct OscServer {
    pub event_rx: Receiver<OscEvent>,
    pub send_tx: Sender<OscEvent>,
    pub listen_port: u16,
    pub send_addr: String,
}

impl OscServer {
    pub fn new(listen_port: u16, send_addr: String) -> Result<Self> {
        let (event_tx, event_rx) = bounded::<OscEvent>(256);
        let (send_tx, send_rx) = bounded::<OscEvent>(256);

        let listen_addr = format!("0.0.0.0:{listen_port}");
        let socket = UdpSocket::bind(&listen_addr)?;
        socket.set_nonblocking(true)?;
        info!("OSC listening on {listen_addr}");

        let send_addr_clone = send_addr.clone();

        {
            let socket_recv = socket.try_clone()?;
            let tx = event_tx.clone();
            std::thread::spawn(move || {
                let mut buf = [0u8; 8192];
                loop {
                    match socket_recv.recv_from(&mut buf) {
                        Ok((size, _addr)) => {
                            if let Ok(packet) = rosc::decoder::decode_udp(&buf[..size]) {
                                flatten_packet(packet.1, &tx);
                            }
                        }
                        Err(ref e) if e.kind() == std::io::ErrorKind::WouldBlock => {
                            std::thread::sleep(std::time::Duration::from_millis(5));
                        }
                        Err(e) => {
                            error!("OSC recv error: {e}");
                        }
                    }
                }
            });
        }

        {
            let send_socket = UdpSocket::bind("0.0.0.0:0")?;
            std::thread::spawn(move || {
                while let Ok(event) = send_rx.recv() {
                    let msg = OscPacket::Message(OscMessage {
                        addr: event.addr,
                        args: event.args,
                    });
                    if let Ok(bytes) = rosc::encoder::encode(&msg) {
                        if let Err(e) = send_socket.send_to(&bytes, &send_addr_clone) {
                            warn!("OSC send error: {e}");
                        }
                    }
                }
            });
        }

        Ok(Self {
            event_rx,
            send_tx,
            listen_port,
            send_addr,
        })
    }

    pub fn drain(&self) -> Vec<OscEvent> {
        let mut out = Vec::new();
        while let Ok(e) = self.event_rx.try_recv() {
            out.push(e);
        }
        out
    }

    #[allow(dead_code)]
    pub fn send(&self, addr: &str, args: Vec<OscType>) {
        let _ = self.send_tx.try_send(OscEvent {
            addr: addr.to_string(),
            args,
        });
    }
}

fn flatten_packet(packet: OscPacket, tx: &Sender<OscEvent>) {
    match packet {
        OscPacket::Message(msg) => {
            let _ = tx.try_send(OscEvent {
                addr: msg.addr,
                args: msg.args,
            });
        }
        OscPacket::Bundle(bundle) => {
            for p in bundle.content {
                flatten_packet(p, tx);
            }
        }
    }

use anyhow::Result;
use std::path::{Path, PathBuf};
use tracing::{info, warn};

pub struct AssetManager {
    pub project_path: Option<PathBuf>,
}

impl AssetManager {
    pub fn new() -> Self {
        Self { project_path: None }
    }

    pub fn set_project_path(&mut self, path: PathBuf) {
        self.project_path = Some(path);
    }

    pub fn import_file(&self, src: &Path) -> Result<PathBuf> {
        let project_path = self
            .project_path
            .as_ref()
            .ok_or_else(|| anyhow::anyhow!("No project path set вЂ” save project first"))?;

        let assets_dir = project_path
            .parent()
            .unwrap_or(Path::new("."))
            .join("assets");

        std::fs::create_dir_all(&assets_dir)?;

        let file_name = src
            .file_name()
            .ok_or_else(|| anyhow::anyhow!("Invalid file name"))?;

        let dst = assets_dir.join(file_name);

        if dst == src {
            return Ok(dst);
        }

        if dst.exists() {
            warn!("Asset {:?} already exists, skipping copy", dst);
            return Ok(dst);
        }

        std::fs::copy(src, &dst)?;
        info!("Asset imported: {:?} в†’ {:?}", src, dst);
        Ok(dst)
    }

    #[allow(dead_code)]
    pub fn make_relative(&self, abs: &Path) -> PathBuf {
        if let Some(proj) = &self.project_path {
            if let Some(proj_dir) = proj.parent() {
                if let Ok(rel) = abs.strip_prefix(proj_dir) {
                    return rel.to_path_buf();
                }
            }
        }
        abs.to_path_buf()
    }

    #[allow(dead_code)]
    pub fn resolve(&self, rel: &Path) -> PathBuf {
        if rel.is_absolute() {
            return rel.to_path_buf();
        }
        if let Some(proj) = &self.project_path {
            if let Some(proj_dir) = proj.parent() {
                return proj_dir.join(rel);
            }
        }
        rel.to_path_buf()
    }
}

    fn wait_cell(
        ui: &mut Ui,
        cue_id: Uuid,
        field: EditField,
        value: f64,
        width: f32,
        row_h: f32,
        accent: Color32,
        editing: &mut Option<(Uuid, EditField, String)>,
        action: &mut Option<CueTableAction>,
        _indent: u8,
    ) {
        let is_editing = matches!(editing, Some((id, f, _)) if *id == cue_id && *f == field);
        if is_editing {
            if let Some((_, _, ref mut buf)) = editing {
                let r = ui.add_sized(
                    [width, row_h - 4.0],
                    TextEdit::singleline(buf).font(TextStyle::Monospace),
                );
                r.request_focus();
                if r.lost_focus() || ui.input(|i| i.key_pressed(Key::Enter)) {
                    *action = Some(CueTableAction::EditConfirm(cue_id, field, buf.clone()));
                }
                if ui.input(|i| i.key_pressed(Key::Escape)) {
                    *action = Some(CueTableAction::EditCancel);
                }
            }
        } else {
            let txt = if value > 0.0 {
                format_duration(value)
            } else {
                "00:00.00".to_string()
            };
            let label = ui.add_sized(
                [width, row_h],
                Label::new(
                    RichText::new(txt)
                        .color(if value > 0.0 { accent } else { Theme::TEXT_DIM })
                        .monospace()
                        .size(11.0),
                )
                .sense(Sense::click()),
            );
            if label.double_clicked() {
                *action = Some(CueTableAction::StartEdit(
                    cue_id,
                    field,
                    format!("{:.2}", value),
                ));
            }
        }
    }

    fn describe_target(cue: &Cue, cue_names: &std::collections::HashMap<Uuid, String>) -> String {
        match &cue.cue_type {
            CueType::Audio => cue
                .file_path
                .file_name()
                .and_then(|n| n.to_str())
                .unwrap_or("вЂ”")
                .to_string(),
            CueType::Play { target_id }
            | CueType::Pause { target_id }
            | CueType::Stop { target_id }
            | CueType::Fade { target_id, .. } => {
                if let Some(tid) = target_id {
                    cue_names
                        .get(tid)
                        .cloned()
                        .unwrap_or_else(|| "Missing target".to_string())
                } else if !cue.file_path.as_os_str().is_empty() {
                    cue.file_path
                        .file_name()
                        .and_then(|n| n.to_str())
                        .unwrap_or("вЂ”")
                        .to_string()
                } else {
                    "All / None".to_string()
                }
            }
            CueType::Midi {
                channel, message, ..
            } => format!("Ch {} вЂў {}", channel, message.label()),
            CueType::Group { mode, children, .. } => {
                format!("{} ({} cues)", mode.label(), children.len())
            }
        }
    }

    fn row_bg(cue: &Cue, selected: bool, idx: usize) -> Color32 {
        if selected {
            return Theme::BG_SELECTED;
        }
        match cue.state {
            CueState::Playing | CueState::FadingIn | CueState::FadingOut => Theme::BG_ACTIVE,
            CueState::Paused | CueState::Waiting => Theme::BG_PAUSED,
            _ => {
                if idx % 2 == 0 {
                    Theme::BG_ROW
                } else {
                    Theme::BG_ROW_ALT
                }
            }
        }
    }

    fn name_color(cue: &Cue) -> Color32 {
        match cue.state {
            CueState::Playing | CueState::FadingIn => Theme::TEXT_ACTIVE,
            CueState::Paused | CueState::Waiting => Theme::PAUSE_BTN,
            _ => Theme::TEXT,
        }
    }
}

pub enum CueTableAction {
    Play(Uuid),
    Stop(Uuid),
    Pause(Uuid),
    Delete(Uuid),
    MoveUp(Uuid),
    MoveDown(Uuid),
    MoveToGroupOrIndex(Uuid, usize),
    StartEdit(Uuid, EditField, String),

    SetColor(Uuid, CueColor),
    AssignTarget(Uuid, Uuid),
}

fn status_label(state: &CueState) -> (&'static str, Color32) {
    match state {
        CueState::Stopped => ("stopped", Theme::TEXT_DIM),
        CueState::Waiting => ("вЏі pre-wait", Theme::PAUSE_BTN),
        CueState::Playing => ("в–¶ playing", Theme::TEXT_ACTIVE),
        CueState::Paused => ("вЏё paused", Theme::PAUSE_BTN),
        CueState::FadingIn => ("в†— fade in", Theme::ACCENT2),
        CueState::FadingOut => ("в† fade out", Theme::ACCENT),
        CueState::Loading => ("loadingвЂ¦", Theme::ACCENT),
        CueState::Error(_) => ("вљ  error", Theme::STOP_BTN),
    }
}

pub fn format_duration(secs: f64) -> String {
    if secs <= 0.0 {
        return "--:--".to_string();
    }
    let m = (secs / 60.0) as u32;
    let s = secs as u32 % 60;
    let cs = ((secs.fract()) * 100.0) as u32;
    format!("{m:02}:{s:02}.{cs:02}")
}

fn vol_to_db(vol: f32) -> f32 {
    if vol <= 0.001 {
        -60.0
    } else {
        20.0 * vol.log10()
    }
}

fn db_to_vol(db: f32) -> f32 {
    if db <= -60.0 {
        0.0
    } else {
        10f32.powf(db / 20.0)
    }
}

        }

        // Р›РёРЅРёРё Fade In Рё Fade Out
        if cue.fade_in_secs > 0.0 {
            let x0 = secs_to_x(cue.start_secs);
            let x1 = secs_to_x((cue.start_secs + cue.fade_in_secs).min(eff_end));
            painter.line_segment(
                [pos2(x0, rect.bottom() - 14.0), pos2(x1, rect.top() + 8.0)],
                Stroke::new(2.0_f32, Theme::ACCENT2),
            );
        }
        if cue.fade_out_secs > 0.0 {
            let x0 = secs_to_x((eff_end - cue.fade_out_secs).max(cue.start_secs));
            let x1 = secs_to_x(eff_end);
            painter.line_segment(
                [pos2(x0, rect.top() + 8.0), pos2(x1, rect.bottom() - 14.0)],
                Stroke::new(2.0_f32, Theme::ACCENT),
            );
        }

        // Р¦РµРЅС‚СЂР°Р»СЊРЅР°СЏ РѕСЃСЊ
        painter.line_segment(
            [pos2(rect.left(), mid_y), pos2(rect.right(), mid_y)],
            Stroke::new(0.5_f32, Theme::BORDER),
        );

        // РљСѓСЂСЃРѕСЂ РІРѕСЃРїСЂРѕРёР·РІРµРґРµРЅРёСЏ
        if cue.is_active() && cue.position_secs > 0.0 {
            let px = secs_to_x(cue.position_secs);
            painter.line_segment(
                [pos2(px, rect.top()), pos2(px, rect.bottom())],
                Stroke::new(2.0_f32, Color32::WHITE),
            );
        }

        // РњР°СЂРєРµСЂС‹ Start / End / Loop
        Self::draw_marker(
            &painter,
            secs_to_x(cue.start_secs),
            rect,
            Theme::MARKER_START,
            "в–ј START",
        );

        if cue.end_secs.is_some() {
            Self::draw_marker(
                &painter,
                secs_to_x(eff_end),
                rect,
                Theme::MARKER_END,
                "в–ј END",
            );
        }

        if cue.loop_region.enabled {
            Self::draw_marker(
                &painter,
                secs_to_x(cue.loop_region.start_secs),
                rect,
                Theme::MARKER_LOOP,
                "в–ј L-IN",
            );
            Self::draw_marker(
                &painter,
                secs_to_x(cue.loop_region.end_secs),
                rect,
                Theme::MARKER_LOOP,
                "в–ј L-OUT",
            );
        }

        // РЁРєР°Р»Р° РІСЂРµРјРµРЅРё
        let tick_count = 10_usize;
        for i in 0..=tick_count {
            let t = dur * i as f64 / tick_count as f64;
            let x = secs_to_x(t);
            painter.line_segment(
                [pos2(x, rect.bottom() - 8.0), pos2(x, rect.bottom())],
                Stroke::new(1.0_f32, Theme::BORDER),
            );
            painter.text(
                pos2(x, rect.bottom() - 9.0),
                Align2::CENTER_BOTTOM,
                format!("{:.1}s", t),
                FontId::monospace(8.5),
                Theme::TEXT_DIM,
            );
        }

        // РџРµСЂРµС‚Р°СЃРєРёРІР°РЅРёРµ РјР°СЂРєРµСЂРѕРІ РјС‹С€СЊСЋ
        if resp.dragged() {
            if let Some(pos) = resp.interact_pointer_pos() {
                let secs = x_to_secs(pos.x).clamp(0.0, dur);
                let start_dx = (secs_to_x(cue.start_secs) - pos.x).abs();
                let end_dx = cue
                    .end_secs
                    .map(|e| (secs_to_x(e) - pos.x).abs())
                    .unwrap_or(f32::INFINITY);
                let loop_s_dx = if cue.loop_region.enabled {
                    (secs_to_x(cue.loop_region.start_secs) - pos.x).abs()
                } else {
                    f32::INFINITY
                };
                let loop_e_dx = if cue.loop_region.enabled {
                    (secs_to_x(cue.loop_region.end_secs) - pos.x).abs()
                } else {
                    f32::INFINITY
                } ;

                let min_dx = start_dx.min(end_dx).min(loop_s_dx).min(loop_e_dx);
                if min_dx < 25.0 {
                    if min_dx == start_dx {
                        cue.start_secs = secs.min(eff_end);
                    } else if min_dx == end_dx {
                        cue.end_secs = Some(secs.max(cue.start_secs));
                    } else if min_dx == loop_s_dx {
                        cue.loop_region.start_secs = secs.min(cue.loop_region.end_secs);
                    } else {
                        cue.loop_region.end_secs = secs.max(cue.loop_region.start_secs);
                    }
                }
            }
        }
    }

    fn draw_marker(painter: &Painter, x: f32, rect: Rect, color: Color32, label: &str) {
        painter.line_segment(
            [pos2(x, rect.top()), pos2(x, rect.bottom() - 12.0)],
            Stroke::new(1.5_f32, color),
        );
        painter.text(
            pos2(x, rect.top() + 2.0),
            Align2::CENTER_TOP,
            label,
            FontId::monospace(9.0),
            color,
        );
    }
}
