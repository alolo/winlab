# TaSQ — история изменений

В этом файле публикуются пользовательские изменения между версиями TaSQ.

## 0.9.1 Preview — подготовка к выпуску

**Статус:** кандидат на Preview Release; окончательная сборка и регрессионная проверка ещё должны быть завершены.

### Документация релиза

- Подготовлено описание проекта и пользовательских возможностей.
- Разделены проверенные функции, известные ограничения и функции в разработке.
- Зафиксирована целевая версия пакета `0.9.1`.

### Важно о составе версии

Изменение номера версии само по себе не меняет поведение Audio Engine. Подготовленный version-bump patch предназначен для обновления метаданных версии и не содержит изменений логики воспроизведения.

Полный список изменений непосредственно в программном коде для 0.9.1 необходимо окончательно сверить с предыдущей опубликованной версией перед публикацией GitHub Release. До этой сверки не следует приписывать версии новые функции только на основании того, что они уже присутствуют в текущей тестовой кодовой базе.

### Известные ограничения

- Производительность DVS при высокой многоканальной нагрузке требует дальнейшей проверки.
- Sparse Mixer ещё не подключён к production Audio Engine.
- Межустройственная синхронизация и ряд функций Playlist находятся в разработке.
